# ADR-0001 · 技术选型与功能范围（已定，不得擅自更改）

- **状态**：已接受（用户 2026-11-06 拍板）
- **决策人**：用户
- **执行者**：接手开发的 AI
- **相关性**：影响全部模块。要推翻必须经用户明确同意，并新增 ADR 记录理由。

## 上下文

用户要一个「Win32 + C++ 自绘」的易语言 IDE 现代化外壳：界面语言按 VS 2026，功能范围只按易语言 IDE 有的东西。**用户明确排除 Qt**，要求用先进的自绘方案，要求 DPI 感知、面板任意拖放停靠、打开即窗口设计器、图标必须用 VS 2026 官方图标、字体与配色必须可在设置里改。代码编辑器（表格化 + 流程线）本期不做，只留接口。

## 决策

| 主题 | 决定 | 主要理由 |
|---|---|---|
| 窗口 | Win32 单 HWND 自绘控件树（1 主窗 + N 浮动面板窗 + 1 拖拽预览层） | 逐像素控制，无框架税 |
| 2D 渲染 | **Direct2D 1.1 + DirectWrite + WIC** | 微软为 UI 设计的 GPU 2D（底子是 D3D11）；抗锯齿/alpha/几何/图层齐全 |
| 合成与动画 | **DirectComposition** | 面板飞入/归位/重排由 DWM 合成，不占 UI 线程 |
| 不用 GDI | — | 无 GPU/无抗锯齿/alpha 差，深色与高分屏全废 |
| 不用 DX12 | — | 自管堆/fence/描述符，给 IDE 用是自找闪屏与 TDR |
| 不用 Qt / WinUI3 / WebView2+Monaco | — | 用户排除 Qt；后两者要么要运行时，要么不是 C++ 自绘 |
| 依赖 | WIL（header-only, MIT） | 免写 Release()，不引框架 |
| 停靠 | **自研可拆分布局树**（Split/Tabs 递归 + 5 区罗盘 + 浮动窗 + 自动隐藏） | C++/Win32 没有许可友好的成熟 VS 式停靠库（Qt ADS/KDDockWidgets 绑 Qt，CodeJock 收费） |
| 图标 | Microsoft 官方 **Visual Studio 2026 Image Library**（已放在 `assets/icons/`） | 用户要求「必须用 VS2026 图标、不许自造」；官方包 13,236 文件，含控件图标，实测可做到零自绘 |
| 字体/颜色 | 全部走 `theme::Tokens` + `settings.json` 覆盖层，控件内禁止硬编码 | 用户要求 14 个区域都能在设置里改 |
| AI 可操作 | 所有 UI 动作必须有等价 `Command` 或 `ui.*` bridge 方法（命名管道 JSON-RPC，仅 loopback + token） | 用户要求「所有地方留接口，让 AI 能操作整个 IDE 的 UI」，否则无法自动验收与回归 |
| 交付粒度 | Part-by-Part（P0~P22），一次一个，用户确认后才下一个 | 用户明确要求；避免一口气写完再返工 |
| 代码编辑器 | 本期**不做**，只定 `IEditorSurface` 接口 + 空占位 | 表格化 + 流程线是真正难点，等 UI 稳定后单独立项，先做 200~300 行 spike |
| 范围禁区 | Git / Copilot / NuGet / Test Explorer / 容器 / 扩展市场 / 多级 Solution / 账号登录 / 云同步 / 遥测 / 自动更新 / 插件商店 / 团队协作 | 易语言 IDE 上没有的一律不做 |
| 联网 | 产品**完全不联网** | 同上，无账号无遥测 |

## 后果

- 正面：无框架依赖、单 exe、可对像素级打磨；图标与字体都有明确来源，不会跑偏。
- 代价：自绘控件的基础设施（命中/焦点/滚动/IME）要自己做扎实，M0/M1 阶段必须先打地基，否则后面每个控件都要重写一遍。
- 风险：停靠系统工作量集中在 P6~P10，必须严格按文档 4.1 的布局树模型实现，不做超纲能力（如「面板内再分屏」）。
- 已知未决：见 `open-questions.md`。
