## 2. 支持库是怎么封装的（一句话版）

支持库 = **元数据** + **命令实现** + **组件声明** 三块，缺一块就是「看得见、编不过」：

- **元数据** `.elib`（GBK 纯文本库）→ `tools/pack_epp.py --store` → `.epp`（zip stored，IDE 侧读包只有 EOCD→中央目录→偏移直取，**没实现 inflate**，所以必须 stored）
- **命令实现** `libsrc/core_support` → `g++ -std=c++20 -O2 -Iinclude -c src/*.cpp` + `ar rcs` → `libcore_support.a`
- **组件声明** `mfc_controls` 头文件里的 `@component/@name/@type` 注解 → IDE 启动解析 → 组件箱（42 个控件、675 属性、53 事件）
