# 文档索引

这些文档写于开发过程中，是**施工依据**而非事后总结，所以语气是"要做成什么样"。

两点语境，读之前先知道：

1. **文中出现的「用户」= 项目作者本人**（需求提出方），不是你在用的产品的终端用户。
2. **旧路径映射**：项目早期把开发环境与运行环境分成 `开发环境/` 和 `运行环境/` 两套，后来合并成一套 `环境/`；本开源版又进一步把源码、工具、素材拆成 `src/`、`tools/`、`assets/`。文档里若出现 `环境\\...`，指的就是**编译输出目录**（本仓库对应 `bin/`）。
