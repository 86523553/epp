# 代码编辑器完整体验 · 开发路线图

> 2026-11-11 定稿。目标：把代码编辑器做到与真机易语言一致的一整套——
> 敲命令高亮 → 打字触发补全 → 回车选中 → 流程块绘制 → 选择/复制/删除 → 撤销。
> 治「抓瞎」：每个阶段都有明确的完成判据，做完一段验收一段，禁止跨段混做。

## 0. 真机易语言的完整交互链（临摹对象，逐帧对齐这个）

```
① 打字（任意可打印字符，含 IME 上屏）
     ├─ 语句区立刻进入行内编辑（无需双击）
     └─ 每上一个字 → 弹出候选列表（拼音首字母/前缀/子串过滤）
② 候选列表
     ├─ 分类着色：系统语法/数据类型/支持库函数/项目符号…
     ├─ ↑↓ 或 Tab 移动；左侧显示命令分类图标
     └─ 右侧/下方详情区：参数签名 + 备注（悬停延迟 ~200ms）
③ 回车/双击选中候选
     ├─ 普通命令 → 补成 `命令 ( 参数 )`，光标进第一个参数位
     ├─ 流程块头（如果/判断开始…）→ 自动补 () + 生成配对结构 + 光标进条件
     └─ 已带括号不重复补（防 `如果 (())`）
④ 高亮（每帧，随文本实时）
     ├─ 命令关键字深蓝（如果/否则/计次循环首…）
     ├─ 注释绿（' 开头整行）、字符串绿（"…"）
     ├─ 数字/逻辑值（真/假）暗红
     └─ 自定义类型/程序集名 各自色
⑤ 选择
     ├─ 单击 = 定位光标进编辑（不选任何字）
     ├─ 拖拽 = 字符级选区；双击 = 选词；三击 = 选整行
     ├─ 从行号栏拖/点 = 整行选中（真机如此）
     ├─ Shift+方向键扩选；Ctrl+A 全选
     └─ 选区跨流程块头时，块范围自动展开（含隐藏结构行）
⑥ 复制/剪切/粘贴
     ├─ Ctrl+C/X 按⑤的展开范围，粘贴回表格逐行还原
     └─ 粘贴时重新做语法配对检查（防止粘出半截块）
⑦ 删除
     ├─ 选区删除（Delete/Backspace/直接打字替换选区）
     ├─ 删块头 = 删整块（头到尾+隐藏结构）
     ├─ 块尾行内 Backspace 到命令名 → 弹警告或整块删
     └─ 删空 = 留一条空语句行（不能删到零行）
⑧ 撤销/重做：Ctrl+Z/Y，按"原子操作"合并（打字连续合并、块生成一次撤销还原）
```

## 1. 施工顺序（S0→S8，串行，每段验收后才开下一段）

### S0 · 地基：文档/参考-真机表格规格-MECHANICS.md §6 流程线收尾（半天）
当前流程线零高度投影已改一半，先把它按真机验收收尾，不留半成品进下一段。
- [ ] 隐藏行（否则/如果结束）零高度，线投影到相邻可见行
- [ ] 点击轨道/空白永不出"否则"文字（code_hit 行高口径统一）
- 完成判据：你实机验收「如果」块线型 = 真机截图。

### S1 · 撤销/重做栈（1 天）★最先做
没有它后面每步都危险，改错一次就回不来。
- 快照模型：整份 `g_eAsms` 深拷贝进 `vector<Snap>`，上限 100 步
- 原子操作 = 一次提交行 / 一次块生成 / 一次删除 / 一次整块删
- Ctrl+Z / Ctrl+Y，编辑态内外都可用
- 完成判据：打字→Ctrl+Z×N 逐步回退→Ctrl+Y 逐步恢复，不崩不乱。

### S2 · 键鼠编辑基础全套（1-2 天）
把"不丝滑"一次性解决：
- 拖拽选字（WM_MOUSEMOVE 按住）、双击选词、三击选行
- Shift+←→↑↓ 扩选；Home/End 两段式（先首非空白再行首）
- Ctrl+←/→ 词跳、Ctrl+Backspace/Delete 词删、Ctrl+A
- 光标闪烁（CreateCaret/SetCaretBlinkTime 或自绘 WM_TIMER 530ms）
- 完成判据：拿记事本同操作对比，每个动作结果一致。

### S3 · 语法高亮完善（半天）
已有 `code_tokenize`，补全分类与颜色即可：
- 真机色值：关键字深蓝 #000080、注释/字符串绿、数字/真假暗红 #800000（见 MECHANICS.md）
- 自定义数据类型名、程序集名识别着色
- 完成判据：对照真机同一段代码截图逐色一致。

### S4 · 命令补全 MVP（2-3 天）★核心卖点
- 触发：编辑态每上一个字符即过滤弹层（非 Ctrl+Space 手动式）
- 数据源：`核心支持库.epp` 命令表（已有 237 条）+ 精易模块（e-packager 解包提取，一次生成 JSON 落 `工具/`）
- 过滤：前缀 + 子串 + **拼音首字母**（`如`→`r`、`果`→`g`，移植 su-lang `modules/pinyin.py` 表）
- 弹层：列表自绘（GDI），分类着色照 su-lang `COMPLETION_CATEGORY_COLORS`
- 键盘：↑↓/Tab 移动、回车/双击选中、Esc 关闭；候选显示时回车**优先选中候选**而非提交行
- 完成判据：打「rb」出「如果」，回车 → `如果 ()` 光标进括号。

### S5 · 候选详情 + 类成员补全（1 天）
- 悬停候选 → 右侧详情：参数表、备注（数据已在 epp 命令表里）
- 输入 `对象.` → 弹该类型成员列表（数据类型表 + 成员命令 295 条已有）
- 完成判据：打「窗口1.」出组件属性/方法列表。

### S6 · 选择→复制/删除 闭环精修（1 天）
S2 有基础选区后，把流程块语义缝上：
- 块范围展开复制（已做一半）+ 剪切/粘贴还原
- 删块头整块删（已做）→ 补块尾/分支行内删除的整块确认
- 行号栏点/拖=整行选择（真机交互）
- 完成判据：全选删除一次清干净（用户已报的 bug 在此段闭环）。

### S7 · 断点（半天 UI + 调试生效另立专项）
- 行号栏右侧留 18px 槽，单击切换红点（数据结构：`set<int> g_breakLines`）
- 双击行号=断点条件弹窗（可后置）
- **F5 真停下来** = ptools `epl dap` 对接，属编译后端专项，不在本路线图
- 完成判据：红点能加、能存盘、能随块移动（插行后行号重映射）。

### S8 · 性能与手感抛光（1 天）
- 局部脏矩形（打字只刷当前行 ± 流程线带）
- 垂直滚动条可拖；等宽字体开关
- 完成判据：2000 行子程序打字不掉帧、不闪。

## 2. 依赖关系（为什么必须这个顺序）

```
S1 撤销 ──┬── S2 键鼠 ──┬── S4 补全 ── S5 详情/成员
          │             │
S0 流程线 ┘             └── S6 块语义选择（要 S2 选区 + S0 零高度）
S3 高亮（独立，随时插队）
S7 断点（独立，只依赖行号栏）
S8 性能（最后，前面全稳了再动重绘）
```
- 撤销必须最先：S2/S4 大量改动没有回退保护=玩火。
- 补全必须在键鼠之后：弹层接管回车/方向键，选区模型不先定会打架。
- 块语义复制删除必须在选区标准化之后：现在的"行选区"是临时产物。

## 3. 每段交付纪律

1. 一段 = 一次编译成功（EXIT=0）+ 拷 `环境\ide.exe` + 报 MD5，不截图。
2. 用户实机验收通过 → 本文件勾选 ✅ → 才开下一段。
3. 验收不过 → 停在原地修到过，禁止"先往下做"。
4. 每段开工前备份 `main.cpp` 到 `备份\`。
