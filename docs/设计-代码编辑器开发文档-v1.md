## 1. 真机行为基线（搜索资料结论）

来源：维基百科「易语言」条目、Elang-Skills 实测笔记、su-lang 全量复刻。三条硬事实：

1. **即时补全**：不是 Ctrl+Space 才弹，是**每敲一个字就弹候选**。真机原话级描述：
   「内置首拼和全拼输入法，直接输入拼音后可通过自动补全匹配中文命令」「有即时补全，命令可直接模糊猜测」。
2. **表格混合编辑**：子程序头/参数/局部变量/语句是**一张表**（不是纯文本），
   声明区单元格填表，语句区行内编辑——这正是我们的 CRow 模型方向，没有走错。
3. **流程辅助线**：「流程控制命令线会显示流程辅助线提示执行跳到何处」——
   否则/块尾不占文字行、由线表达，零高度投影（我们 S0 正在做的）。

**真机完整交互链（临摹总目标，逐帧对齐）**：

```
① 打字 → 立刻进入该语句行的行内编辑（任意可打印字符，无需双击）
② 每上一个字 → 候选弹层实时过滤（汉字前缀 / 子串 / 拼音首字母 / 全拼）
③ ↑↓/Tab 选候选 → 回车/双击选中：
     普通命令补成「命令 ()」光标进参数位；流程块头额外生成配对结构+画线
④ 全程语法着色实时：关键字深蓝 / 注释·字符串绿 / 数字·真假暗红 / 类型名青
⑤ 选择：单击定位；拖拽选字；双击选词；三击/行号栏点=整行；Shift+方向扩选
⑥ 复制/剪切/粘贴：跨流程块自动展开块范围（含隐藏结构行）
⑦ 删除：选区删；删块头=整块删；永远保留至少一条空语句行
⑧ Ctrl+Z/Y：按原子操作合并（连续打字合一格、块生成/删除各一格）
⑨ 断点：行号槽单击红点（F5 真停=编译后端专项，另立）
```

## 2. 参考源码拆解（su-lang-main，1030+3000 行，Qt 版）

| 模块 | 文件 | 关键设计（可直接搬到我们 Win32/GDI 版） |
|---|---|---|
| 补全触发 | `ui/completion.py`(984行) | `textChanged` 信号 → 每字符重过滤；弹层是独立 popup，**eventFilter 抢键盘**：popup 可见时 Return/Enter/Tab=选中候选（不进编辑器提交）；Space=收起弹层并把空格插入正文 |
| 拼音检索 | `modules/pinyin.py` | 每个命令预生成 `首拼(rg)+全拼(ruguo)` 两个隐藏键，过滤=前缀∪子串∪拼音前缀 |
| 分类着色 | `ui/completion_details.py` | `COMPLETION_CATEGORY_COLORS`：系统语法 #dcdcaa / 内置类型 #4ec9b0 / 支持库函数 #7fc98d / 项目符号 #75bfff / 参数 #9cdcfe…（12 类，照抄即可） |
| 候选详情 | `ui/completion.py` `_schedule_detail` | 悬停候选行 → 延迟定时器(~200ms) → tooltip 显示「签名+备注+分类」；切行即重排 |
| 插入逻辑 | `ui/code_editor.py` `_insert_completion`(~3162) | `avoid_duplicate_call_parentheses`（已有括号不重复补）、`empty_call_completion`（参数个数→光标落点）、**cursor_offset 机制**（插入后光标定位到第一个参数） |
| 流程配对 | `ui/code_editor.py` `_insert_flow_pair`(3362) | 行尾=独立流程头才触发；if_start/judge_start 一次生成**双分支骨架**（真分支空行+否则+假分支空行+尾）；`_has_following_flow_pair_tail` 防重复；`beginEditBlock` 保证一次撤销还原全部 |
| 隐藏行 | `ui/table_code_editor.py` `_flow_only_table_commands` | 注册表 `hidden=True` 名单驱动（否则/如果结束/如果真结束/默认/判断结束），不显示不占高，线投影到相邻可见行 |
| 折叠 | `ui/code_editor.py` `_apply_flow_fold_visibility` | 块头可折叠整块（结构隐藏∪折叠隐藏两个集合）——**二期可选**，一期不做 |
| 命令表 | `modules/flow_commands.py` | key/pair/role/paint/hidden/closes/branch 七元组注册表，所有模块共读一份——**我们的 kFlowHeadsG 等散表要合成这一张** |

## 4. 架构设计（本编辑器 = 四个对象，一个都不多）

```
┌─ CodeDoc（数据）────────────────────────────────┐
│ g_eAsms 唯一真值；行=声明行|语句行 混合装配（CRow）  │
│ 变更 API 全部收口：doc_insert/doc_erase/doc_set_text │
└──────────────┬─────────────────────────────────┘
               │ 每次变更 push Snap（S1）
┌─ UndoStack ──┴───────────────┐   ┌─ CompletionEngine（S4）────────┐
│ vector<Snap> ≤100；merge 规则 │   │ 数据源=命令表+项目符号+拼音键     │
│ Ctrl+Z/Y 弹出→回写 CodeDoc    │   │ 状态机: idle→popup(每字符过滤)  │
└──────────────────────────────┘   │ →accept(插入+光标偏移)→idle   │
                                   └───────────────────────────────┘
┌─ View（绘制+输入，单文件内分区）───────────────────┐
│ 坐标唯一口径：code_row_h_ex（隐藏行=0 高度，一切走它） │
│ hit / paint / scroll / ed_geometry 四路共享行表     │
│ 编辑态：caret/anchor 单字符标尺（S2 状态机）          │
│ 弹层：owned popup 窗口，子类化抢键盘（同 su-lang 策略）│
│ 断点槽：行号栏右侧 18px，红点命中=行号区单击          │
└──────────────────────────────────────────────────┘
```

设计铁律（违反=又抓瞎）：
1. **行高只有一个函数**（`code_row_h_ex`）——历史上 hit/paint 口径分裂就是 bug 之源。
2. **变更只有一个入口**（CodeDoc API）——undo、补全、粘贴全走它，旁路写 body 禁止。
3. **弹层可见时键盘归弹层**（回车=选中候选），隐藏后归编辑器——su-lang eventFilter 同款。
4. **补全数据 = 离线生成 JSON + 启动加载**（e-packager 解精易模块一次），运行时零解析。

## 5. 数据设计（新增两份，都是启动时加载）

| 文件 | 内容 | 生成方式 |
|---|---|---|
| `工具\补全数据\commands.json` | 全部命令：名/英文名/分类/参数表(名,类型,可空,备注)/返回类型/是否流程头/配对尾 | 核心库=现有 gen_from_krnln.py；精易模块= e-packager unpack 精易模块目录 源码提取（一次脚本） |
| `工具\补全数据\symbols.json` | 当前工程的 子程序/参数/局部变量/常量/程序集（保存时增量重建） | IDE 自己写盘时顺手生成 |

拼音键（首拼+全拼）构建时预存进 commands.json，运行时只做前缀/子串匹配。

## 8. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| IME（中文输入法）与补全弹层抢焦点 | 高 | 弹层用 owned popup 不抢焦点；候选接管键走父窗 WM_KEYDOWN 转发（su-lang 同架构） |
