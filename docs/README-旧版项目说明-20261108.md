# epp / 易屁屁 —— 易语言风格 IDE

## 编译

双击 `源码\编译.bat`（MinGW g++，0 warning 标准）。

等价命令行：

```
C:\mingw64\bin\g++.exe -std=c++17 -O2 -municode -mwindows -static ^
  -static-libgcc -static-libstdc++ -Wall -Wextra -Wno-unused-parameter ^
  -Wno-missing-field-initializers 源码\main.cpp -o 环境\ide.exe ^
  -lgdiplus -lgdi32 -luser32 -lole32 -ladvapi32 -lshell32 -lcomdlg32 ^
  -lmsimg32 -limm32 -lwinmm
```

注意：MinGW 的 ld 打不开含中文的输出路径，编译脚本先输出到 `%TEMP%` 再拷回来。
资源目录按 `<exe>/assets/icons/`、`<exe>/sounds/`、`<exe>/核心支持库/` 找 —— **`环境/` 必须保持扁平**，`ide.exe` 要和这几个目录同级。

## 运行

双击 `环境\ide.exe`。

| 参数 | 作用 |
|---|---|
| `ide.exe 文件.e` | 直接导入并打开 .e |
| `--screenshot 图.png` | 离屏渲染一帧到 PNG 后退出（自验用，1600×1000） |
| `--shot-lib` / `--shot-lib-shut` | 支持库页（全展开 / 默认收起） |
| `--shot-edit` | 代码页「选中行 + 行内编辑」 |
| `--shot-prop` | 属性页 + 基本组件页 |

## 我们自己的库

### 1. 支持库（一个文件：`核心支持库.epp`）

`环境\核心支持库\核心支持库.epp`（377 KB，**stored zip，不压缩**）—— IDE 启动优先扫 `*.epp`，读包里的「命令.txt」当库表；旧 `*.elib` 只作兜底。

```
manifest.json    中文元信息（格式/版本/统计）
命令.txt          中文命令表（237 条 / 16 分类）—— 与旧 .elib 同一套语法
组件.txt          中文组件表（42 组件 / 675 属性 / 53 事件 / 5 方法）
include/*.h       43 个头文件（组件类声明）
```

为什么 stored：C++ 不用实现 inflate，读中央目录 + 偏移直接取字节（`main.cpp` 的 `epp_zip_entry()`，约 60 行）。

```
python 工具\pack_epp.py --name 核心支持库 --elib 工具\_打包源\核心支持库\核心支持库.elib ^
    --comp-dir 环境\组件库\核心组件库\include --out 环境\核心支持库\核心支持库.epp --store
python 工具\pack_epp.py --list 环境\核心支持库\核心支持库.epp
python 工具\pack_epp.py --dump 环境\核心支持库\核心支持库.epp 组件
```

`.elib` / `.sulib` 已退回 `工具\_打包源\核心支持库\`，只当打包源，不再放进 `环境\`。

### 2. 静态库（一个文件）

`环境\静态库\libcore_support.a` + `include\` —— 来自 su-lang 的 `lib/core_support`（17 个 .cpp / 295 导出符号 / 161 个 `Core*` 函数）。
编译易代码时链接它，`#include "text.h"` 即可。

### 3. 组件库（属性/事件/方法）

`环境\组件库\核心组件库\include\*.h` —— IDE 启动直接解析：

```c
// @component button
// @name 按钮
class CSuButton ... {
    // @name 标题
    // @type 文本型
    // @group 基本
    SULANG_MFC_PROPERTY(text);
    // @name 被单击
    // @group 事件
    SULANG_MFC_EVENT(click);
};
```

- 一个子目录 = 一个组件支持库；`include/` 下所有 `.h` 都扫（`component_support.h` 除外）
- **加组件/属性/方法/事件 → 换文件重启 IDE 就生效，IDE 代码不用改**
- 属性控件按类型自动选：逻辑型→真假、枚举→下拉、颜色/字体→资源行、其余→文本框
- 「窗口」由 IDE 内置（33 属性 / 24 事件）
- 打开 `.e` 时按 XML 属性顺序原样显示；支持库多出来的补「支持库 · 分组」；`.e` 有而库里没的进「源码属性」，一个不丢

## 三层，别混（判断“库全不全”前先看这）

| 层 | 落在哪 | 现状 |
|---|---|---|
| 组件框架/宏 | su-lang `mfc_controls`（`BasicControl<CWnd>`、`SULANG_MFC_*`） | 与 `参考\su-lang-main` 同 MD5 |
| 命令实现 | su-lang `core_support` 的 `Core*` 函数 + 自补 | `环境\静态库\libcore_support.a`（161 个函数） |
