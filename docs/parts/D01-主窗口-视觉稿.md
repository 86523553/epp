## 范围（3 句内）

冷启动第一屏：自绘标题栏 + 菜单栏 + 工具条 + 四区停靠（左组件箱 / 中设计器 / 右属性 / 底输出）+ 状态栏。
窗体 `Form1`（640×480）上放 6 个控件，「按钮1」处于选中态（8 手柄 + 对齐线 + 属性/事件联动）。
浅色主题、菜单下拉、罗盘拖放**不在本稿**。

## 自动化/落档证据

- 窗口真值：`docs/e-lang-ui-dump.json`（只读枚举 `EnumChildWindows` + `GetMenu`，未注入、未 hook）。
- 设计稿结构：Ardot 画板 `2:1`，命名节点（`T1 标题栏`…`T5 状态栏`、`P1 组件箱`、`P0 文档区`、`P2 属性`、`P3 输出`）与 `ui.tree` 的 path 语义一一对应，便于日后写 `.uiscript` 断言。

4. 图标全部为本稿内联矢量（28/26/20/16 四档），**与 §22 的 VS 2026 官方图库不是同一套**；编码时用 `assets/icons/map.json` 里的官方图标替换，形状差异以官方为准。
