## 做了什么

把初版「暗色 IDE」外壳推翻重做，按 VS 2026 的真实结构落地：

| 行 | 高度(DIP) | 内容 |
|---|---|---|
| 标题栏 | 30 | logo + 11 个菜单 + 搜索框(Ctrl+Q) + 最小化/最大化/关闭（自绘，无系统标题栏）|
| 工具栏 | 28 | 11 个官方 VS 图标（新建/打开/保存·撤销/重做·剪切/复制/粘贴·运行/停止/生成）+ 调试 / Any CPU / 易程序 三个下拉 |
| 间隔 | 6 | 深色缝隙（对应截图里的 #1C1C1C 带）|
| 标签条 | 26 | 活动标签＝描边圆角 chip（accent 描边 + 左侧 2px 竖条 + 图钉 + 关闭），另两个普通标签 |
| 导航条 | 23 | 窗体1 › _启动窗口 › 按钮1 三段下拉 |
| 主体 | 自适应 | 左「组件箱」卡片 · 中设计器画布 · 右上「解决方案资源管理器」/ 右下「属性」· 底部「输出」 |
| 状态栏 | 26 | 左：就绪 + 工程名；右：主题 / 缩放 / 行 / 列 / CRLF / UTF-8 |

关键视觉语汇（全部照截图实测）：
- 工具窗口＝**内嵌圆角卡片**（#282828 底、#3A3A3A 1px 描边、8 DIP 圆角、距窗口边 8 DIP），不是贴边老式面板。
- 活动标签＝**描边 chip**，不是填充式页签。
- 三行 chrome 用 #1C1C1C / #262626 / #2B2B2B 分层，行间用 #0E0E0E 黑缝分隔。
- accent 取截图实测 `#9184EE`（该截图是紫色系主题）。

## 工程侧

- CMake 多模块静态库：`el_core`（令牌）/ `el_gfx`（D2D+DWrite+WIC 图标）/ `el_shell`（布局+绘制）/ `elang_ide.exe`。
- 自绘窗口边框：`WM_NCCALCSIZE` 去掉系统标题栏，`WM_NCHITTEST` 手写 8 向缩放 + 标题拖动，窗口按钮走客户区命中。
- DPI：PerMonitorV2，四档缩放按 DIP 布局，150% 下实测窗口 2400×1500。
- 图标：接 `assets/icons/vs`（官方 13,236 个里的 62 个），WIC 解码 → D2D 位图；因官方 PNG 只有一套（部分是给浅色主题的深灰），加载时按「低亮度+低彩度」自动提亮单色图标，彩色图标原样。

## 已知差距（离「99%」还差什么）

1. **图标只接了工具栏/树/组件箱三处**，卡片标题栏、搜索框、状态栏还是字体字形（Segoe MDL2）。
2. **字体**：用的是 Microsoft YaHei UI + Cascadia Mono；VS 2026 用 Segoe UI Variable Text / Segoe UI Variable Display，本机未确认存在。
3. **菜单没有下拉**：只有文字，点击无反应（P3 才做）。
4. **无悬停态**：按钮/菜单/标签/树的 hover 高亮未实现。
5. **面板不可拖动**：卡片位置是算出来的，没有停靠系统（P6）。
6. **标题栏右键菜单、Snap 布局、窗口圆角**：未验证。
7. 150% 下 16px 图标被放大到 24px，略有模糊（官方 PNG 只有 16px 一档；官方 SVG 未接）。

## 复现

```
powershell -ExecutionPolicy Bypass -File .\build.ps1     # 配置+编译+复制图标
易语言安装目录lang-bld\bin\elang_ide.exe
```
构建目录必须是 ASCII 路径（CMake 清单步骤在中文路径下会崩）。
